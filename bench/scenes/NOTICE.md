# Scene fixtures

These scene files come from Armada II Refit (https://github.com/cedrichaase/armada2-refit),
`testbench/scene/scenes/`, at commit 749332ed081ae6e8656a0b6a1fb30363e963a759.
They hold only ODF names and numbers, and are kept byte for byte so one file
runs on Refit's bench and on STA64's.

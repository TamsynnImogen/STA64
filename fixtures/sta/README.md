# .sta fixtures

`Data/` is a tiny install: two loose ODFs, and the mod `StaMod`, whose
content is the single archive `stamod.sta` (generated by `sta_vfs`'s
`sta::tests::fixture_archive`; `STA64_WRITE_FIXTURES=1 cargo test -p sta_vfs
fixture_is_current` rewrites it). The archive overrides `fakira.odf` with a
self-include of Data's copy, adds `fnew.odf` in a deep non-standard folder,
and whites out `fdefiant.odf`.

# CON-09 synthetic glTF fixture

`fx_cruiser.glb` is an original, public-domain 2.0 GLB generated by
`python3 fixtures/models/generate_gltf.py`. It is a 24-vertex, 12-triangle
right-handed cube with explicit normals, tangents, UV0, UV1 and RGBA vertex
colors. Two PNGs are embedded as buffer views: a red/blue checker base color
image and a flat normal image. Its mask material uses the second UV set,
nearest/clamp sampling, a 0.9 alpha factor, 0.2 metalness, 0.7 roughness,
double-sided rendering, and a half-strength normal map.

No game asset or external model was used. The fixture is deliberately small
and may be regenerated deterministically with Python's standard library.

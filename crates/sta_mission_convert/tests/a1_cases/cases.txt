# Authored cases of the Armada I front end (LUA-15e): invented DLL shapes, no game data.
# Read by gen_cases.py (the ORIGINAL tools/a1_to_lua.py) and by tests/a1.rs.
#
# Global directives:
#   const NAME <addr>            a named address; `{NAME}` is `0x..`, `{NAME+20}` adds decimal 20
#   import <dll> <symbol>        an import-table slot, 4 bytes apart from 0x10060000; `{iat:key}` is
#                                `DWORD PTR ds:0x<slot>` (key: plain name, or the symbol for `??..`)
#   export <symbol> <expr>       an export of the mission DLL
#   string <addr> <text>         a string in the image
#   base <addr>                  code of every mission DLL built by `run` (instructions follow)
#   rbase <addr>                 code of every rule DLL
# Per case: `case <name>` ... `end`, `code <addr>` / `rcode <addr>` (instructions, 2 spaces),
# `run lift <addr>` (lift one function of the mission DLL, then render it),
# `run mission` (convert the pair; the rule DLL exists when an `rcode` block does).
